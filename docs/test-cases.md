# 测试用例

当前自动化测试覆盖：

- Bearer token 成功与失败。
- /v1/check 返回 200。
- start hand 返回兼容响应且不产生过早建议。
- 完整 NLH 事件流在轮到英雄时返回真实翻牌前/翻牌后策略建议。
- 延迟看牌事件流允许开手不发英雄牌、其他玩家先行动，并在英雄轮到操作时以更晚序号 DealCards；响应必须在 500ms 内带合法真实建议。
- 完全相同事件重试返回 208。
- 未开始牌局直接发事件返回 Broken hand。
- 跳序、同序号不同内容和并发安全的存储语义。
- 全部 2,598,960 种五张牌的标准牌型数量。
- 5～7 张最佳五张牌、踢脚、轮子顺和公共牌平分。
- 河牌随机对手的 990 种精确枚举。
- 多人 equity 平分、固定种子可复现和输入重复牌校验。
- 自动算法选择、精确规模上限、取消后部分结果及精确结果缓存。
- 翻牌前 169 类查表的完整性和基本强弱关系。
- 全部 376,992 种短牌五张组合、A-6-7-8-9 和两种牌型排序。
- 短牌 36 张牌组的精确 Equity。
- PLO4/PLO5 恰好使用两张手牌与三张公共牌，以及随机对手模拟。
- PLO6 恰好使用两张手牌与三张公共牌、随机对手模拟和默认采样数。
- 策略开池、弃牌、价值下注、听牌半诈唬、弱牌跟注 EV 和全下安全降级。
- 翻牌后负 Call EV 可配置强制弃牌；空气牌逐街跟注边际与连续跟注惩罚可配置，显式关闭时保持旧行为。
- 拟人化不得把负 EV 或空气牌边际保护产生的弃牌重新改成跟注。
- 强度等级差异、固定种子 C-bet、PLO/短牌策略和合法金额保护。
- 六种人格参数、固定种子思考时间、有界拟人动作和玩家画像策略调整。
- 玩家观察幂等、先验平滑、类型分类、去重窗口和玩家容量淘汰。
- 每次 API 调用访问日志、事件各结果日志、稳定决策 ID，以及凭证/原始牌不入日志。
- 牌桌行动轮转、加注后重开行动、盲注/底池/筹码、完整/增量公共牌与建议 deviation。
- PLO6 从 HTTP 事件到真实策略返回的契约测试。
- 默认配置校验、未知配置项拒绝，以及引擎/人格/日志开关。
- 1,326 种 NLH 起手牌的整体入池范围约束、JJ 面对多次加注不误弃，以及短码面对超额下注按可支付 AllIn 金额决策。
- 大盲翻牌前无需补注时推导 Raise 而不是 Bet，避免合法动作保护把开池建议降级为 Check。
- 两人桌翻牌前由 SB/Dealer 先行动、翻牌后由 BB 先行动，且不会把合法 BB 动作拒绝为 Game logic error。
- 唯一剩余对手全下时只推导 fold/call 或 check，不产生无人能够响应的 raise/bet/allin。
- 同一 AinP 实例中同一机器人连续两手使用不同 AiProfile 时，分别解析本手的人格和等级，不沿用上一手配置。
- 遍历 NLH 全部 1,326 种两张组合，显式 VPIP/PFR 范围误差不超过 1/1326；`cmd/profilesim` 对每个生产 AiProfile 至少执行 100 万手真实策略模拟。
- `cmd/profitsim` 对 FPCH_90_5 执行至少 100 万手完整牌局收益基准，输出大小底池胜率/收益、BB/100 和 95% 置信区间；固定种子必须可复现。
- 日志审计对 Game logic error、Wrong seq_num、动作类型 deviation 和未知 AiProfile 默认降级执行零容忍门禁，并输出风格/人格/等级分层指标。
- 日志审计识别延迟 DealCards、拒绝或漏 advice、延迟决策 P95、负 EV 跟注、低边际高牌跟注、连续两条/三条街高牌跟注、河牌低边际一对跟注、公共牌对子跟注、顺子/同花听牌落空后的河牌跟注及连续追牌、可免费看牌却弃牌、低胜率全下、河牌高胜率过牌及 AiProfile 频率偏差；按事件指纹去重状态错误，并保存有界异常样例。策略回归覆盖 As4s 在 Kh3dQcJs/Ks 牌面的转牌弱听牌和河牌公共牌对子保护弃牌。可免费看牌却弃牌配置为零容忍门禁。
- 特殊风格至少模拟 10 万手，验证 VPIP 100%、翻前 Raise 和翻后进攻概率误差不超过 1%、任何路径均不 Fold；审计必须从普通异常门禁排除其负 EV/低胜率行为，并单独验证输赢、动作和到达各轮次统计。
- 运行后台页面、Bearer 鉴权、状态/报告 API、并发刷新保护、异步报告生成及原子落盘。

后续必须加入基于 pokerbot/engine/aicon 生成客户端的契约测试：启动 ainp 后由真实客户端依次发送完整事件流，并验证 JSON200/JSON400/JSON500 解码。另需维护来自脱敏历史牌局的 golden replay，不允许修改期望结果来掩盖策略回归。

日志审计需要覆盖进程重启边界：启动宽限期内缺少 `start_hand_extended` 的旧手后续事件应单独统计，不能让其中的 DealCards 误触发运行期拒绝发牌门禁；宽限期外的相同错误必须继续失败。

日志审计还需覆盖跨玩家时间线：玩家 A 已结束某 table/hand，或尚未结束但同桌事件序号已经明显前进，超过配置阈值后玩家 B 才从 StartHand 补发同一手并产生 advice/Fold 偏差时，必须归入迟到补发玩家事件流，不能误报为 AinP 实时建议执行失败。

发布门槛：gofmt 无差异、go vet ./...、go test -race ./...、go build ./... 全部通过；接口兼容变更需同时更新 OpenAPI 和契约测试。牌型或 equity 变更还必须运行 internal/equity 基准并记录明显的性能回退。
