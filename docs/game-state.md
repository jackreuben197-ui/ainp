# 牌局状态

MemoryHandStore 同时保存严格事件序号、指纹和规范化 GameState。首个事件必须是序号 1 的 start_hand_extended；相同事件重放返回 208，相同序号不同内容或跳序返回 400。

GameState 从现有 AiCon 事件重建：玩法、人格、玩家顺序/角色、起始与剩余筹码、盲注/前注、英雄牌、公共牌、街道、逐街与总投入、底池、当前最高投入、最小完整加注、弃牌/全下、翻牌前主动方和待行动玩家。金额保持 AiCon 的浮点筹码单位，与 pokerbot 当前 `/100` 转换一致。

行动顺序利用 pokerbot start payload 的既有排序与角色推导：翻牌前从大盲/straddle 后一位开始，翻牌后从小盲方向开始；加注后从加注者下一位轮转，需要补齐投入的玩家重新获得行动机会。只有 NextToAct 等于英雄时 HTTP 才返回建议，避免把过早建议留在 pokerbot answer channel。

flop 接受 3 张牌；turn/river 同时兼容只发送新增牌或发送完整公共牌，并校验已有前缀不变。end_hand 后拒绝新的牌局行动。

状态默认保留 24 小时、最多 50,000 手，每分钟批量清理一次，避免每个事件扫描全部牌局。状态仍是单实例内存实现；多实例部署需要按手牌键固定路由，或换成具备原子序号和状态更新能力的 Redis 实现。
